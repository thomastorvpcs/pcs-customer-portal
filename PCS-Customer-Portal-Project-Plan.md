## Purpose

This document outlines the delivery plan for Stage 1 of the PCS Wireless Customer Portal. It covers the five-sprint schedule, milestone dates, and the scope delivered in each sprint. The dashboard is built progressively — each sprint adds its corresponding KPI section to the Dashboard page as the feature area it represents goes live.

## 1. Sprint 1 — Infrastructure, Authentication & Orders

**Dates:** May 18 – May 29, 2026
**Milestones:** M0 (May 29) — Infrastructure ready · M1 (May 29) — Portal accessible

### Infrastructure & Deploy Pipelines

| Task | Description |
|------|-------------|
| CI/CD pipeline | GitHub Actions workflow deploying to Render on merge to main |
| Staging environment | Dedicated staging instance on Render for QA before production releases |
| Production environment | Production web service on Render with environment variable management |
| PostgreSQL database | Database provisioned on Render with staging and production instances |
| Next.js scaffold | Project initialised with Next.js 14 App Router, Tailwind CSS, and TypeScript |

### Authentication (US-01–04)

| Task | User Story |
|------|------------|
| Auth0 sign-in integration | US-01 — Customers can log in to the portal |
| Password reset flow | US-02 — Customers can reset a forgotten password |
| PCS staff credential provisioning | US-03 — PCS staff provision portal access for existing customers |
| Protected route middleware | US-04 — All pages require authentication |

### Navigation & Global UI (US-67, US-68, US-70)

| Task | User Story |
|------|------------|
| Desktop sidebar navigation | US-67 — Persistent sidebar with all navigation links |
| Mobile bottom tab bar and hamburger drawer | US-68 — Mobile-friendly navigation |
| Responsive layout | US-70 — Portal works on both mobile and desktop |

### Order Management (US-12–16)

| Task | User Story |
|------|------------|
| Order listing page | US-12 — View a list of all orders |
| Order status filtering | US-13 — Filter orders by status |
| Order ID / PO Number search | US-14 — Search orders by ID or PO number |
| Order detail page | US-15 — View full order details including line items and shipping |
| Order status timeline | US-16 — View order progress through fulfilment steps |

### Dashboard — Sprint 1 Additions (US-06)

| Addition | Description |
|----------|-------------|
| Dashboard shell | Main landing page after login |
| Open Orders KPI card | Count of orders in active status |
